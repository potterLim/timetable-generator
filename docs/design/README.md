# 제품 UI 구현 기준

이 문서는 제품 레이아웃, 상호작용, 색상과 타이포그래피의 구현 기준을 기록한다. 특정 학기 카탈로그나 사용자 계획이 포함된 화면 캡처는 저장소에 보관하지 않는다.

## 핵심 작업

사용자는 한 화면에서 과목을 찾고, 분반 선호와 대안 과목을 정하고, 계획별 개인 일정을 더해 추천 시간표를 비교하며, 시간 정보가 없는 선택을 확인할 수 있어야 한다. 과목 탐색·시간표·계획 상태 사이의 맥락을 유지하는 것이 시각적 단순함보다 우선한다.

## 넓은 화면

- 56 DIP 앱 헤더와 44 DIP 계획 탭을 사용한다.
- 본문은 과목 탐색, 시간표, 계획 검사기의 세 영역으로 구성한다.
- 1600 DIP 이상에서는 양쪽 패널을 항상 표시한다.
- 시간표가 남는 너비를 사용하며 화면의 가장 강한 시각적 초점이 된다.
- 목록 항목은 중첩 카드 대신 같은 표면의 행과 구분선으로 묶는다.

## 반응형 동작

- 1600 DIP 이상에서는 양쪽 패널을 본문에 표시한다.
- 1280~1599 DIP에서는 과목 탐색을 본문에 유지하고 계획 검사기를 오버레이 패널로 전환한다.
- 1080~1279 DIP에서는 폭을 줄인 과목 탐색을 본문에 유지하고 계획 검사기를 오버레이 패널로 연다.
- 900~1079 DIP에서는 과목 탐색과 계획 검사기를 모두 오버레이 패널로 전환한다.
- 최소 창 크기는 900×640 DIP이다.
- 오버레이가 열리면 첫 조작 요소로 포커스를 옮기고, `Esc`로 닫으면 호출한 버튼으로 포커스를 복원한다.

## 제품 상태

- 시간 미정 분반은 선택할 수 있지만 충돌 검증 대상에는 포함하지 않는다.
- 시간 미정 선택이 있으면 "시간 정보가 없어 충돌 여부를 확인할 수 없는 과목이 있습니다."라는 상태를 계속 표시한다.
- 계획 전체를 충돌 없음으로 표현하는 것은 모든 선택의 시간이 확인된 경우에만 허용한다.
- 각 분반은 선호·가능·제외 중 하나로 명시하고, 추천은 선호 분반을 먼저 사용하며 제외 분반을 사용하지 않는다.
- 서로 다른 과목을 `이 중 하나`로 묶은 선택에서는 정확히 한 과목의 분반 하나만 추천에 배치한다.
- 개인 일정은 현재 계획에만 저장하고 수업과 같은 시간표 항목이자 추천의 고정 충돌 조건으로 취급한다.
- 자동 저장, 오프라인 캐시, 다운로드 실패, 빈 계획, 검색 결과 없음, 추천 결과 없음 상태를 정상 화면과 같은 품질로 제공한다.

## 시각 토큰

라이트는 순백 대신 푸른 안개 같은 표면 계층을 사용한다.

- 창 기반: `#EAF1F8`
- 상단과 패널: `#E7EFF8`
- 입력과 떠 있는 표면: `#F2F6FA`
- 기본 본문: `#162235`
- 보조 본문: `#53667C`
- 강조 전경과 채움: `#0047FF`
- 선택 배경: `#D5E2FF`

다크는 청회색 대신 따뜻한 흑색과 크림색을 사용한다.

- 창 기반: `#1A1A1A`
- 패널: `#20201E`
- 입력: `#242421`
- 떠 있는 표면: `#282724`
- 기본 본문: `#F5EFE0`
- 보조 본문: `#C7C1B5`
- 강조 전경: `#8BA9FF`
- 주요 동작 채움: `#1B4FDE`

작은 강조 텍스트는 다크 배경에서 `#0047FF`를 직접 사용하지 않는다. 역할별 본문, 상태색, 조작 경계, 포커스와 채움 대비는 자동 테스트로 고정한다. 간격은 4 DIP 기반 척도와 2 DIP 광학 보정을 사용한다. 일반 카드 반지름은 8~10 DIP, 최상위 대화상자는 12 DIP로 제한해 계층을 구분한다.

## 타이포그래피

Pretendard 1.3.9의 Regular, Medium, SemiBold, Bold 정적 글꼴을 앱에 포함하고 아이콘 glyph를 제외한 모든 제품 텍스트와 Flyout에 적용한다. 운영체제에 설치된 글꼴과 무관하게 Windows와 macOS에서 같은 글자 폭과 굵기 체계를 유지한다.

## 의도적 제품 교정

기준 시안의 `다른 조합 찾기`는 이전·다음 탐색과 역할이 겹치므로 실제 제품에서는 `PNG로 저장`으로 교체한다. 과목 결과는 페이지를 나누지 않고 가상화한다. 시각이 있는 항목이 없으면 시간축 대신 빈 상태를 사용한다. 일정이 있으면 현재 추천의 수업과 개인 일정만 기준으로 가장 이른 일정이 속한 정각 30분 전부터 마지막 일정 종료보다 늦은 첫 30분 경계까지 표시한다. 끝 경계에는 시간 레이블을 두지 않으며 가로 안내선은 30분 단위를 사용한다. 화면의 요일 열은 추천 간 비교를 위해 후보 전체의 범위를 공유하고, PNG는 각 후보의 시간·요일 범위를 독립적으로 다시 계산한다.
