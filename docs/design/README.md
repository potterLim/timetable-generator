# 제품 UI 구현 기준

[`planning-workspace-target.png`](planning-workspace-target.png)을 데스크톱 앱의 기준 화면으로 사용한다.

## 핵심 작업

사용자는 한 화면에서 과목을 찾고, 계획에 추가하고, 추천 시간표를 비교하며, 시간 정보가 없는 선택을 확인할 수 있어야 한다. 과목 탐색·시간표·계획 상태 사이의 맥락을 유지하는 것이 시각적 단순함보다 우선한다.

## 넓은 화면

- 64 DIP 앱 헤더와 48 DIP 계획 탭을 사용한다.
- 본문은 과목 탐색, 시간표, 계획 검사기의 세 영역으로 구성한다.
- 1440 DIP 이상에서는 양쪽 패널을 항상 표시한다.
- 시간표가 남는 너비를 사용하며 화면의 가장 강한 시각적 초점이 된다.
- 목록 항목은 중첩 카드 대신 같은 표면의 행과 구분선으로 묶는다.

## 반응형 동작

- 1280 DIP 이상에서는 양쪽 패널을 본문에 표시한다.
- 1080~1279 DIP에서는 계획 검사기를 오버레이 패널로 전환한다.
- 900~1079 DIP에서는 과목 탐색과 계획 검사기를 오버레이 패널로 전환한다.
- 최소 창 크기는 900×640 DIP이다.
- 오버레이가 열리면 첫 조작 요소로 포커스를 옮기고, `Esc`로 닫으면 호출한 버튼으로 포커스를 복원한다.

## 제품 상태

- 시간 미정 분반은 선택할 수 있지만 충돌 검증 대상에는 포함하지 않는다.
- 시간 미정 선택이 있으면 "시간 정보가 없어 충돌 여부를 확인할 수 없는 과목이 있습니다."라는 상태를 계속 표시한다.
- 계획 전체를 충돌 없음으로 표현하는 것은 모든 선택의 시간이 확인된 경우에만 허용한다.
- 자동 저장, 오프라인 캐시, 다운로드 실패, 빈 계획, 검색 결과 없음, 추천 결과 없음 상태를 정상 화면과 같은 품질로 제공한다.

## 시각 토큰

- 강조색: `#0F6CBD`
- 기본 본문: `#17191C`
- 보조 본문: `#5D6673`
- 구분선: `#E2E5E9`
- 보조 표면: `#F7F8FA`
- 성공: `#107C41`
- 경고: `#B35C00`
- 오류: `#C42B1C`
- 간격은 4 DIP 배수를 사용하고 일반 표면 반지름은 8 DIP를 넘기지 않는다.

## 의도적 제품 교정

기준 시안의 `다른 조합 찾기`는 이전·다음 탐색과 역할이 겹치므로 실제 제품에서는 `PNG로 저장`으로 교체한다. 과목 결과는 페이지를 나누지 않고 가상화하며, 선택한 과목에 7~10교시 수업이 있을 때 시간표가 해당 교시까지 확장된다.
