# 사용 방법

Timetable Generator는 과목과 분반을 선택하면 겹치지 않는 시간표를 자동으로 구성합니다.  
개인 일정을 함께 반영하고, 완성한 시간표를 이미지나 캘린더로 내보낼 수 있습니다.

## 다운로드 및 실행

배포 파일은 이 저장소의 [GitHub Releases](https://github.com/potterLim/timetable-generator/releases)에서 내려받으세요.

### Windows

1. 파일 이름에 `win-x64`가 포함된 ZIP을 내려받습니다.
2. ZIP의 압축을 새 폴더에 모두 풉니다.
3. `TimetableGenerator.exe`를 실행합니다.

### macOS

1. 파일 이름에 `osx-arm64`가 포함된 ZIP을 내려받습니다.
2. 압축을 풀고 `Timetable Generator.app`을 응용 프로그램 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 Timetable Generator를 엽니다.

## 처음 시작하기

앱을 처음 실행하면 현재 학기의 과목 정보를 불러오고 기본 시간표를 만듭니다.  
과목 정보를 처음 불러올 때는 인터넷 연결이 필요합니다.

불러온 과목 정보와 시간표는 기기에 저장됩니다.  
다음 실행부터 마지막으로 사용하던 상태를 이어갈 수 있습니다.  
과목 정보를 불러오지 못하면 인터넷 연결을 확인한 뒤 화면의 **다시 시도**를 누르세요.

화면은 세 영역으로 구성됩니다.

- **과목 찾기**: 과목을 검색하고 추가합니다.
- **시간표**: 가능한 시간표를 비교하고 내보냅니다.
- **시간표 편집**: 선택한 과목과 개인 일정을 확인하고 수정합니다.

창 크기에 따라 좌우 영역은 접힐 수 있습니다.  
시간표 위쪽의 버튼으로 언제든 다시 열 수 있습니다.

## 과목 찾기

1. **과목 찾기**에서 과목명, 과목 코드 또는 교수 이름을 검색합니다.
2. 필요하면 개설 단위와 이수 구분을 선택해 결과를 좁힙니다.
3. 원하는 과목의 **+** 버튼을 누릅니다.
4. 분반이 여러 개라면 **수강 선택 설정**에서 수강할 수 있는 분반을 정한 뒤 저장합니다.

검색 결과는 입력에 맞춰 바로 갱신됩니다.  
영문 대소문자나 띄어쓰기가 달라도 검색할 수 있습니다.

분반은 다음 세 가지로 설정할 수 있습니다.

- **선호**: 가능한 시간표에서 먼저 선택합니다.
- **가능**: 선호 분반을 사용할 수 없을 때 대안으로 선택합니다.
- **제외**: 시간표에 포함하지 않습니다.

선호 또는 가능 분반을 하나 이상 남겨야 합니다.  
저장한 설정은 **시간표 편집**에서 언제든 바꿀 수 있습니다.

### 여러 과목 중 하나만 선택하기

서로 다른 과목 중 하나만 수강하려면 **수강 선택 설정**에서 대안 과목을 검색해 같은 수강 선택으로 묶습니다.

예를 들어 경영학 입문과 경제학 입문을 묶으면 **2개 과목 중 1개 선택**으로 표시됩니다.  
앱은 묶인 과목 중 하나의 분반만 배치하며 각 과목의 선호·가능·제외 설정을 함께 반영합니다.

## 가능한 시간표 비교하기

과목을 추가하거나 설정을 바꾸면 가능한 시간표가 자동으로 다시 구성됩니다.

- 위쪽의 화살표로 이전·다음 시간표를 확인합니다.
- 가운데 번호에서 현재 위치와 가능한 시간표 수를 확인합니다.
- **일정 목록**을 누르면 수업과 개인 일정을 목록으로 확인할 수 있습니다.
- 시간표의 항목을 선택하면 상세 정보를 확인할 수 있습니다.

요일과 시간 범위는 현재 시간표에 맞게 자동으로 조정됩니다.  
토요일이나 일요일 일정이 있으면 해당 요일까지 함께 표시됩니다.

가능한 시간표가 없다면 **시간표 편집**을 열어 다음 항목을 확인하세요.

- 서로 겹치는 과목이 있는지
- 개인 일정과 충돌하는 분반이 있는지
- 너무 많은 분반을 제외하지 않았는지
- 여러 과목 중 하나를 고르는 수강 선택을 올바르게 설정했는지

## 개인 일정 추가하기

수업 외에 정해진 시간이 있는 활동도 시간표에 함께 넣을 수 있습니다.

1. **개인 일정 추가**를 누릅니다.
2. 일정 이름과 요일을 선택합니다.
3. 시작 시간과 종료 시간을 정합니다.
4. 필요하면 분반, 담당자, 장소를 입력하고 저장합니다.

한 일정에 여러 요일을 선택할 수 있습니다.  
개인 일정은 선택한 시간표 탭에 저장되며, 해당 탭의 모든 후보 시간표에 고정 일정으로 반영됩니다.  
개인 일정과 겹치는 수업 분반은 가능한 조합에서 제외됩니다.

추가한 일정은 시간표에서 선택하거나 **시간표 편집**에서 열어 수정하고 삭제할 수 있습니다.

## 시간 미정 과목 확인하기

학교에서 수업 시간을 제공하지 않은 분반은 **시간 미정**으로 구분되어 **시간표 편집**에 표시됩니다.

시간을 알 수 없는 분반은 주간 시간표에 배치하거나 다른 일정과의 겹침을 판단할 수 없습니다.  
최종 수강 신청 전 학교의 공식 안내에서 수업 시간을 확인하세요.

## 여러 시간표 관리하기

시간표 탭 영역의 **+** 버튼으로 서로 독립된 시간표를 여러 개 만들 수 있습니다.

- 탭을 선택해 다른 시간표로 이동합니다.
- **시간표 편집**에서 시간표 이름을 선택해 이름을 바꿀 수 있습니다.
- 선택한 과목과 개인 일정을 모두 비울 수 있습니다.
- 더 이상 필요하지 않은 시간표를 삭제할 수 있습니다.

각 시간표의 과목, 분반 설정, 개인 일정, 이름과 마지막으로 선택한 후보 시간표는 자동으로 저장됩니다.  
앱을 다시 실행하면 마지막 상태에서 이어집니다.

저장에 실패하면 상단 안내에서 **다시 시도**를 누르세요.

## 내보내기

시간표 위쪽의 **내보내기**에서 시간표를 PNG로 저장하거나 캘린더로 내보낼 수 있습니다.

### PNG 이미지

- **현재 시간표 PNG 저장**: 현재 보고 있는 시간표를 이미지 한 장으로 저장합니다.
- **모든 가능한 시간표 PNG로 저장**: 가능한 시간표를 각각 번호가 붙은 이미지로 저장합니다.

시간표별로 최대 24개의 후보를 비교하고 저장할 수 있습니다.  
저장되는 이미지의 요일과 시간 범위는 각 시간표에 맞게 조정되며, 주말 일정과 개인 일정도 함께 포함됩니다.  
시간 미정 과목은 주간 시간표에 배치할 수 없으므로 이미지에는 표시되지 않습니다.

### Google Calendar

**Google Calendar로 내보내기**를 선택하면 시스템 브라우저에서 Google 계정 연결 화면이 열립니다.  
사용할 계정을 선택하고 권한을 승인하면 현재 시간표의 수업과 개인 일정이 학기 기간에 맞춰 반복 일정으로 추가됩니다.

내보내기가 끝나면 Google Calendar에서 추가된 일정을 확인할 수 있습니다.

### Apple Calendar

macOS에서는 **Apple Calendar로 내보내기**를 사용할 수 있습니다.  
처음 내보낼 때 macOS가 캘린더 앱 접근 권한을 요청할 수 있습니다. 권한을 허용하면 내보내기가 이어서 완료됩니다.

권한을 거부했다면 macOS **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 Timetable Generator의 캘린더 앱 접근을 허용한 뒤 다시 시도하세요.

### 같은 이름의 캘린더가 있을 때

같은 이름의 캘린더가 있으면 확인 창이 열립니다.

- **기존 캘린더 대체**: 앱이 만든 일정만 새 시간표로 바꾸고 사용자가 직접 추가한 일정은 유지합니다.
- **새 캘린더 만들기**: 이름 뒤에 번호를 붙여 별도의 캘린더를 만듭니다.

**기존 캘린더 대체**는 같은 이름의 캘린더가 정확히 하나이고, 그 캘린더가 앱이 만든 쓰기 가능한 캘린더일 때만 선택할 수 있습니다.  
그 밖의 캘린더는 덮어쓰지 않으며 새 캘린더로만 저장할 수 있습니다.

## 저장되는 데이터

시간표와 개인 일정은 현재 기기에 자동으로 저장됩니다.  
개발자는 사용자의 시간표와 개인 일정을 수집하거나 개발자 서버에 저장하지 않습니다.

Google Calendar 또는 Apple Calendar로 내보낼 때만 사용자가 승인한 캘린더 서비스에 현재 시간표의 일정이 전달됩니다.  
자세한 내용은 [개인정보처리방침]({{ '/privacy/' | relative_url }})을 확인하세요.

## 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 처음 실행할 때 과목 정보를 불러오지 못함 | 인터넷 연결을 확인하고 **다시 시도**를 누릅니다. |
| 가능한 시간표가 없음 | 겹치는 과목과 개인 일정을 조정하고 분반의 선호·가능·제외 설정을 확인합니다. |
| 과목이 주간 시간표에 나타나지 않음 | **시간표 편집**에서 해당 분반이 **시간 미정**인지 확인합니다. |
| 시간표를 저장하지 못함 | 기기의 남은 저장 공간을 확인하고 상단의 **다시 시도**를 누릅니다. |
| PNG를 저장하지 못함 | 다른 파일 이름이나 저장 위치를 선택하고 폴더 쓰기 권한과 남은 공간을 확인합니다. |
| Google Calendar 내보내기가 완료되지 않음 | 브라우저에서 로그인과 권한 승인을 완료하세요. 시간이 초과되면 다시 시도하세요. |
| Apple Calendar 내보내기가 거부됨 | macOS 시스템 설정에서 Timetable Generator의 캘린더 자동화 권한을 허용한 뒤 다시 시도하세요. |

문제가 계속되면 [GitHub Issues](https://github.com/potterLim/timetable-generator/issues)에 사용 중인 운영체제와 화면에 표시된 안내를 함께 남겨 주세요.
