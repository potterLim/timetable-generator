# Timetable Generator 서비스 이용약관

<p class="policy-meta">시행일 및 최종 수정일: 2026년 7월 21일</p>

이 약관은 Timetable Generator의 배포본과 관련 서비스를 이용할 때 적용됩니다. 앱을 사용하면 아래 내용을 확인하고 동의한 것으로 봅니다.

## 1. 제품의 성격

Timetable Generator는 학교 과목 목록에서 과목을 찾고, 충돌 없는 분반 조합과 개인 일정을 바탕으로 학기 시간표를 구성하는 Windows·macOS 데스크톱 앱입니다.

이 제품은 한동대학교가 개발, 운영, 승인 또는 보증하는 공식 서비스가 아닌 개인 프로젝트입니다. 수강 신청, 좌석 확보, 졸업 요건 판정 또는 학교 시스템 변경을 수행하지 않습니다.

## 2. 이용자의 확인 책임

앱은 제공된 카탈로그와 사용자가 입력한 조건을 기준으로 결과를 계산합니다. 과목명, 담당자, 강의실, 수업 시간, 학점, 수강 가능 여부와 학사 일정은 변경되거나 누락될 수 있습니다. 실제 수강 신청과 학사 판단 전에는 반드시 학교의 공식 안내를 최종 기준으로 확인해야 합니다.

사용자는 개인 일정의 제목·담당자·장소 등 자신이 입력하거나 외부 캘린더로 내보내는 정보가 적절한지 확인할 책임이 있습니다.

## 3. 외부 서비스

Google Calendar, Apple Calendar, GitHub와 과목 카탈로그 호스팅은 각 제공자가 운영하는 외부 서비스입니다. 외부 서비스의 장애, 계정 상태, 정책 변경 또는 API 변경에 따라 일부 기능을 사용할 수 없거나 다시 승인이 필요할 수 있습니다.

Google Calendar와 Apple Calendar에 내보낸 데이터는 앱의 로컬 데이터와 별도로 저장됩니다. 앱 삭제나 로컬 데이터 삭제만으로 외부 서비스의 캘린더·일정은 삭제되지 않습니다.

Apple Calendar에서 기존 앱 관리 캘린더 교체를 선택하면 Timetable Generator가 소유 표식을 남긴 일정만 새 내보내기 결과로 교체합니다. 해당 캘린더에 사용자가 직접 추가한 일정과 소유 표식이 없는 일정은 보존됩니다.

## 4. 개인정보와 보안

데이터 처리 범위, Google Calendar 권한, 로컬 보관, 삭제와 권한 철회 방법은 [개인정보처리방침]({{ '/privacy/' | relative_url }})에 따릅니다.

사용자는 비밀번호, OAuth 토큰, 서명 인증서, 학교 원본 데이터 또는 민감한 개인 일정이 포함된 파일과 화면 캡처를 공개 Issue에 게시해서는 안 됩니다. 보안 문제는 [GitHub 비공개 보안 제보](https://github.com/potterLim/timetable-generator/security/advisories/new)를 이용해야 합니다.

## 5. 사용 제한

다음과 같은 방식으로 제품이나 관련 서비스를 사용해서는 안 됩니다.

- 다른 사람의 계정이나 데이터에 권한 없이 접근하는 행위
- Google, Apple, GitHub, 학교 또는 호스팅 제공자의 정책과 관련 법령을 위반하는 행위
- 제품의 이름이나 화면을 사용해 학교 또는 제3자가 공식적으로 보증한 서비스인 것처럼 오인시키는 행위
- 서비스 안정성이나 다른 이용자의 사용을 고의로 방해하는 행위

## 6. 배포와 지식재산권

저장소의 소스 코드와 배포 파일에는 별도의 사용 허가가 명시되지 않은 한 복제, 수정, 재배포 권한이 자동으로 부여되지 않습니다. 앱에 포함된 오픈 소스 구성 요소와 자산에는 배포물의 `ThirdPartyNotices`에 수록된 각 라이선스가 적용됩니다.

`Timetable Generator`와 프로젝트 자산을 사용해 다른 제품이나 공식 서비스를 사칭해서는 안 됩니다.

## 7. 제공 상태와 책임 범위

제품은 현재 상태로 제공됩니다. 개발자는 시간표 후보의 완전성, 학교 데이터의 정확성, 특정 목적에 대한 적합성, 외부 서비스의 지속적 가용성 또는 수강 신청 결과를 보증하지 않습니다.

관련 법령이 허용하는 범위에서, 제품 사용 또는 사용 불가로 발생한 수강 신청 실패, 일정 누락, 데이터 손실, 외부 서비스 변경이나 기타 간접 손해에 대해 개발자는 책임을 부담하지 않습니다. 다만 법령상 제한할 수 없는 책임은 제외합니다.

## 8. 변경과 지원 종료

기능, 지원 운영체제, 데이터 형식과 이 약관은 제품 개선, 보안 또는 외부 서비스 변경에 따라 수정될 수 있습니다. 중요한 변경은 저장소 또는 GitHub Release 안내에 반영하며, 변경 후 제품을 계속 사용하면 개정 내용을 확인한 것으로 봅니다.

제품 또는 특정 외부 연동은 사전 고지 후 지원을 종료할 수 있습니다. 보안상 긴급한 경우에는 먼저 기능을 제한한 뒤 안내할 수 있습니다.
