# Timetable Generator 이용약관

<p class="policy-meta">시행일: 2026년 7월 21일 · 최종 수정일: 2026년 7월 30일</p>

이 약관은 Timetable Generator를 이용할 때 적용됩니다.  
앱을 사용하면 아래 내용을 확인하고 동의한 것으로 봅니다.

## 1. 제품의 성격

Timetable Generator는 학교 과목 목록에서 과목을 찾고 충돌 없는 분반 조합과 개인 일정을 바탕으로 학기 시간표를 구성하는 Windows·macOS 데스크톱 앱입니다.

이 제품은 한동대학교가 개발·운영·승인·보증하는 공식 서비스가 아닌 개인 프로젝트입니다.  
수강 신청을 대신하거나 수강 정원·졸업 요건을 보장하지 않으며 학교 시스템을 변경하지 않습니다.

## 2. 이용자의 확인 책임

앱은 제공되는 과목 정보와 사용자가 입력한 조건을 바탕으로 시간표를 계산합니다.  
과목명, 담당자, 강의실, 수업 시간, 학점, 수강 가능 여부와 학사 일정은 변경되거나 누락될 수 있습니다.  
수강 신청이나 학사 관련 결정을 내리기 전에는 반드시 학교의 공식 안내를 최종 기준으로 확인해야 합니다.

사용자는 개인 일정의 제목·담당자·장소 등 자신이 입력하거나 외부 캘린더로 내보내는 정보가 적절한지 확인할 책임이 있습니다.

## 3. 외부 서비스

Google Calendar, Apple Calendar, GitHub와 과목 정보 제공 서버는 각 제공자가 운영하는 외부 서비스입니다.  
외부 서비스의 장애, 계정 상태, 정책 또는 API 변경에 따라 일부 기능을 사용할 수 없거나 다시 승인이 필요할 수 있습니다.

Google Calendar와 Apple Calendar에 내보낸 데이터는 앱의 로컬 데이터와 별도로 저장됩니다. 앱 삭제나 로컬 데이터 삭제만으로 외부 서비스의 캘린더·일정은 삭제되지 않습니다.

**기존 캘린더 대체**를 선택하면 앱이 만든 일정만 새 시간표에 맞게 바뀝니다.  
해당 캘린더에 사용자가 직접 추가한 일정은 유지됩니다.
